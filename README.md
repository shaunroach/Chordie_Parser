# Nodes & Edges

Nodes & Edges is an experimental web-based storytelling toy about power, uncertainty, and hierarchy inside a fantastical kingdom. Every node represents a character whose motives and abilities are only partially known. Edges describe who outranks whom, forming layered structures that shape how the society responds to crises.

## Concept Highlights
- Nodes carry partially known attributes plus a running personal log of deeds.
- Edges encode hierarchy; moving a node changes how influence flows.
- Event prompts pressure the society, surfacing tensions or new information.
- Discovery actions reveal hidden traits or even surface entirely new figures.

## Getting Started
1. Open `index.html` in any modern browser (no build step needed).
2. Use a static server such as `npx serve` if you want live reload: `npx serve .`

## Gameplay Loop
- Inspect the current hierarchy; click a node to read their dossier and log.
- Trigger events to force the structure to respond—watch influence shift.
- Run discovery operations to learn more about murky attributes.
- Reassign subordinates to reshape the chain of command on the fly.
- Add or unveil fresh nodes to widen the political landscape.
